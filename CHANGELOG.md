## [0.1.0] - 2026-07-19

### Added

- Transport-independent provider adapter protocol.
- Deterministic JSON transcript provider with structured replay errors.
- Core profile with eighteen provenance, temporal, transparency, absence, separation, and determinism checks.
- Text, JSON, JUnit XML, and SARIF 2.1.0 reports.
- CLI commands for profile execution, profile inspection, and example initialization.
- Conforming and deliberately broken example transcripts.
- Standard-library `unittest` suite and local CI check script.
